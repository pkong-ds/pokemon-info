# pkong-ds scoop bucket

Personal Scoop bucket for
[pokemon-info](https://github.com/pkong-ds/pokemon-info) — a terminal
Pokedex with TUI browsing and instant offline name completion.

```
scoop bucket add pkong-ds https://github.com/pkong-ds/scoop-bucket
scoop install pokemon-info
```

Manifests here consume the release archives published at
[pkong-ds/pokemon-info/releases](https://github.com/pkong-ds/pokemon-info/releases).
