# pkong-ds/tap

Homebrew tap for [pokemon-info](https://github.com/pkong-ds/pokemon-info) —
a terminal Pokedex with TUI browsing and instant offline name completion.

```
brew tap pkong-ds/tap
brew install pokemon-info
```

Formulas here consume the release archives published at
[pkong-ds/pokemon-info/releases](https://github.com/pkong-ds/pokemon-info/releases).
